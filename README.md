# LibreSign Coverage

Centralized public code coverage reports for repositories in the LibreSign organization.

This repository is being set up with the upstream [octocov](https://github.com/k1LoW/octocov) central mode. Reports and badges will be published with GitHub Pages; the existing CI continues generating coverage reports.
